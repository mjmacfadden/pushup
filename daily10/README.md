# Daily 10 — Social Habit Fitness Wireframe

A polished interactive concept prototype for a social fitness app built with vanilla HTML, CSS and JavaScript.

## Concept
**Ten reps. Every day. Together.**

The product is intentionally not a conventional workout tracker. The core loop is a tiny daily commitment plus social accountability: do 10 push-ups, protect the streak, and don't be the last person in your crew to check in.

## Included
- Today dashboard
- 10 push-up daily goal
- Streak visualization
- Friend activity / social pressure
- Challenges
- Profile and stats
- Light/dark mode
- Responsive mobile layout
- Interactive check-in with toast confirmation
- No frameworks or dependencies

## Run
Open `index.html` in a modern browser. No build step or server is required.
